# DocToPdfTool

多功能文档格式转换工具，支持 **文档转 PDF**、**Word 转 PDF**、**Excel 转 PDF**、**Excel 转图片**、**PPT 转 PDF**、**PPT 转 Word**、**PPT 转图片**、**Word 转图片**、**图片转 PDF**、**PDF 加密/解密**、**PDF 水印**、**PDF 页面管理**、**PDF 提取图片**、**PDF 压缩**、**PDF 加页码**、**Excel 拆分/合并**、**图片批量处理**、**证件照排版**、**提取纯文本**、**文本翻译**、**OCR 文字识别**、**PDF 转 Word**、**PDF 转 Excel**、**PDF 转 PPT**、**PDF 转图片**、**PDF 转扫描件**、**PDF 转 HTML/SVG/MD/灰度/PDF-A/XPS**、**Word 转 MD/EPUB**、**Excel 转 CSV/HTML/JSON/MD**、**PPT 转 HTML/TIFF**、**拆分 PDF** 和 **合并 PDF** 等 42 项功能。

## 界面

- **首页**：程序启动后展示功能主页，顶部为搜索框（输入关键词即可模糊匹配功能），下方为所有功能按钮网格（水平居中，功能增多时可滚动）
- **功能页**：点击首页功能按钮或搜索结果后，在同一窗口内切换到「左侧导航 + 右侧功能区」布局，并自动定位左侧菜单选中项（自动滚动到可视区）
- **返回首页**：功能页左上角提供「🏠 首页」按钮，可随时返回主页
- **单窗口路由**：首页与功能页之间为同一窗口内的页面切换，不会打开新窗口

## 功能

### 文档转 PDF
- **双引擎转换**：支持 WPS Office 和 Microsoft Office 两种转换引擎，运行时自由切换
- **格式支持**：Word（.doc/.docx）、Excel（.xls/.xlsx）、PPT（.ppt/.pptx）、文本（.txt/.rtf）、HTML（.html/.htm/.mhtml）
- **HTML 转换**：基于 Edge 浏览器 headless 模式，保留原始布局和样式
- **Excel 多工作表**：不做额外页面设置改动，输出与 WPS / Office 自身「导出为 PDF」的默认打印效果一致，完整转换所有工作表
- **批量转换**：支持添加/拖拽多个文档，逐文件显示转换进度
- **拖拽添加**：支持拖拽文档到列表，列表中间显示操作提示

### Word 转 PDF
- **内置引擎，无需外部依赖**：基于 Spire.Doc 本地 DLL，无需安装 Microsoft Office 或 WPS
- **批量转换**：支持同时添加多个 Word 文件，逐个转换
- **拖拽添加**：支持拖拽 Word 文件到列表

### Excel 转 PDF
- **内置引擎，无需外部依赖**：基于 Spire.XLS 本地 DLL，无需安装 Microsoft Office 或 WPS
- **格式支持**：Excel（.xls/.xlsx）
- **三档页面缩放**：
  - `按宽度适应`（默认）— 所有列压缩到一页宽，行继续纵向分页，**列不会被横向切断**
  - `整表缩放到单页` — 每张工作表输出为一页，小表一页看完
  - `实际大小` — 完全按原表列宽分页，超宽时横向分页（还原 Excel 原生打印效果）
- **输出整洁**：转换结果不含附加标注页与提示文字（引擎自动生成的提示工作表会自动剔除）
- **内存优化**：转换前跳过公式重算、转换后自动清理引擎缓存，降低批量转换时的内存峰值
- **批量转换**：支持同时添加多个 Excel 文件，逐个转换
- **拖拽添加**：支持拖拽 Excel 文件到列表

### Excel 转图片
- **内置引擎，无需外部依赖**：本地 DLL 渲染，无需安装 Microsoft Office 或 WPS
- **每表一图**：每张有内容的工作表输出为一张完整图片，命名 `工作簿名_工作表名.png`
- **内容不截断**：整表按内容缩放到单页再渲染，一张表的内容完整呈现在一张图内，不会被分页切开
- **自动裁边**：图片尺寸贴合表格实际内容，不含 A4 纸张的多余空白边距
- **输出整洁**：转换结果不含附加标注文字与提示页
- **尺寸保护**：超大表（如数千行）超出位图上限时自动下调 DPI（下限 24），保证单图完整输出不崩溃
- **可调参数**：支持 DPI（96/150/300，默认 150）、输出格式（JPG/PNG，默认 PNG 无损）
- **临时文件自动清理**：逐表中转 PDF 与分页图片在转换结束后删除（带句柄重试）
- **批量转换**：支持同时添加多个 Excel 文件，逐个转换
- **拖拽添加**：支持拖拽 Excel 文件到列表

### PPT 转 PDF
- **内置引擎，无需外部依赖**：基于 Spire.Presentation 本地 DLL，无需安装 Microsoft Office 或 WPS
- **格式支持**：PowerPoint（.ppt/.pptx）
- **长文档完整转换**：本地 DLL 引擎支持大页数文档完整输出，内容不截断
- **内存优化**：每次转换后强制 GC + 归还内存给操作系统，降低批量转换时的内存峰值
- **批量转换**：支持同时添加多个 PPT 文件，逐个转换
- **拖拽添加**：支持拖拽 PPT 文件到列表

### PPT 转 Word

- **格式支持**：PowerPoint（.ppt/.pptx）→ Word（.docx）
- **两段式转换**：先由 Spire.Presentation 将 PPT 渲染为中间 PDF，再由 Spire.PDF 转换为 DOCX，临时文件自动清理
- **完整输出**：中间 PDF 由本地 DLL 生成，最终 DOCX 完整保留全部页面
- **内存优化**：每次转换后强制 GC + 归还内存给操作系统
- **批量转换**：支持同时添加多个 PPT 文件，逐个转换
- **拖拽添加**：支持拖拽 PPT 文件到列表

### PPT 转图片

- **逐页导出**：每张幻灯片输出为独立图片，命名 `原文件名_1.png`、`原文件名_2.png` …
- **长文档完整转换**：本地 DLL 引擎支持大页数文档完整输出，内容不截断
- **高质量渲染**：开启 `HighQualityImage` 高质量渲染，JPG 使用 100% 质量编码
- **可调参数**：支持 DPI（96/150/300）、输出格式（JPG/PNG，默认 PNG 无损）
- **内存优化**：每页完成即触发回调回收，转换结束强制 GC + 归还内存
- **批量转换**：支持同时添加多个 PPT 文件，逐个转换
- **拖拽添加**：支持拖拽 PPT 文件到列表

### Word 转图片

- **长文档完整转换**：本地 DLL 引擎支持大页数文档完整输出，内容不截断
- **可调参数**：支持 DPI（96/150/300）、输出格式（JPG/PNG，默认 PNG 无损）
- **无 Office 副作用**：不启动 Word 进程，无窗口弹出，单文件耗时远低于 COM 方案
- **批量转换**：支持同时添加多个 Word 文件，逐个转换
- **拖拽添加**：支持拖拽 Word 文件到列表

### PDF 转 Word
- **双引擎转换**：支持 Microsoft Office 和内置引擎（Spire.PDF）两种转换引擎，运行时自由切换
- **内置引擎无需 Office**：基于本地 PDF 引擎，无需安装 Microsoft Office，长文档完整转换
- **大文件分批处理**：超过 20 页的 PDF 自动分批转换后合并，内存峰值可控

- **批量转换**：支持同时添加多个 PDF 文件，逐个转换
- **拖拽添加**：支持拖拽 PDF 文件到列表

### PDF 转图片
- **Windows 内置引擎**：基于 Windows 10/11 内置 PDF 渲染引擎（`Windows.Data.Pdf`），无需额外安装软件
- **批量转换**：支持同时添加多个 PDF 文件，每页生成一张图片
- **拖拽添加**：支持拖拽 PDF 文件到列表
- **可调参数**：支持 DPI（72/96/150，默认 150）、缩放倍率（1×~5×，默认 1×）、输出格式（JPG/PNG）
- **像素上限保护**：单页超过 2.5 亿像素时自动等比缩小，避免 GDI+ 位图内存溢出
- **零依赖**：不依赖 pdfium.dll、Ghostscript 或 Office 组件

### 图片转 PDF
- **零依赖**：纯 .NET 直接写入 PDF 1.4（`BinaryWriter` + DCTDecode），不依赖任何 PDF 库或 Office 组件
- **两种输出方式**：
  - `合成一个 PDF`（默认）— 所有图片按列表顺序合成一个 PDF，一张图一页
  - `每张图各出一个 PDF` — 每张图片单独生成一个 PDF，命名 `文件名_001.pdf`、`文件名_002.pdf` …
- **JPEG 无损嵌入**：普通 JPEG 原图以 DCTDecode 直接嵌入，不重编码，画质零损失、速度更快
- **格式转换**：PNG / BMP / GIF / TIFF 自动铺白底后转 JPEG 嵌入（PDF 不支持透明通道）
- **EXIF 方向纠正**：自动读取手机竖拍照片的方向标记并旋转到正确朝向
- **三档页面尺寸**：
  - `A4 适应`（默认）— 等比缩放放进 A4，按图片横竖自动选择纸张方向，四周留白
  - `A4 铺满` — 等比放大填满 A4，超出部分居中裁切
  - `原始尺寸` — 按图片自身 DPI 换算物理尺寸
- **边距可选**：0 / 5 / 10 / 20 mm（默认 10 mm）
- **顺序调整**：列表顺序即页序，支持上移 / 下移 / 移除，也支持拖拽一次追加多张
- **缩略图预览**：列表显示缩略图与原始像素尺寸，便于核对顺序
- **大图保护**：长边超过 5000 px 自动降采样，避免解码内存峰值过高
- **容错**：单张图片损坏或格式不支持时跳过并提示，不中断整个任务
- **重名保护**：输出文件重名时自动追加序号

### PDF 加密
- **内置引擎，无需外部依赖**：基于本地 PDF 引擎，无需安装 Microsoft Office 或 WPS
- **两种模式**：`加密`（给 PDF 加打开密码）/ `移除密码`（解除已有密码）
- **加密算法**：AES-256（推荐）/ AES-128 / RC4-128（兼容旧版阅读器）
- **打开密码**：必填，需二次确认，防止输入错误导致文件打不开
- **编辑密码可选**：留空则只设置打开密码、不限制编辑与权限；填写后可按预设限制权限
- **权限预设**：`仅查看`（默认）/ `允许打印` / `全部允许` / `自定义`（打印、复制、修改、批注、填表逐项勾选）
  - 选择 `仅查看` 等受限权限时，用打开密码进入后尝试编辑/打印，阅读器（Adobe / WPS / 福昕等）会要求输入编辑密码
  - 若权限为 `全部允许`，编辑与打印不受限制，阅读器不会索要编辑密码
- **移除密码**：需提供编辑密码；若原文件未设置编辑密码，填打开密码或留空即可
- **输出保护**：输出为 `原文件名_已加密.pdf` / `原文件名_已解密.pdf`，不覆盖原文件，重名自动追加序号
- **批量处理**：支持多个文件，单个失败不影响其余，结束后汇总失败清单
- **状态识别**：列表自动标注每个文件「已加密 / 未加密」并显示页数

### PDF 水印
- **内置引擎，无需外部依赖**：基于本地 PDF 引擎在页面内容之上绘制，不依赖 Office 或第三方工具
- **两种类型**：
  - `文字`：自定义内容、字号（8~300）、颜色（灰/红/蓝/黑）
  - `图片`：支持 PNG/JPG/BMP，按页宽比例缩放（默认 30%），建议用透明背景 PNG
- **半透明与旋转**：透明度 10%~70%，角度 0°/30°/45°/90°，默认 45° 斜向
- **平铺模式**：可铺满整页，也可单个居中
- **页码范围**：留空=全部页，支持 `1-3,5` 写法
- **水印不破坏原文字层**：绘制在原内容之上，原文字仍可选中与搜索
- **加密文件识别**：自动检测并提示先用「PDF 加密 → 移除密码」解除
- **输出保护**：输出为 `原文件名_已加水印.pdf`，不覆盖原文件，重名自动追加序号
- **批量处理**：单个失败不影响其余，结束后汇总

### PDF 页面管理
- **缩略图预览**：打开 PDF 后自动渲染每页缩略图，所见即所得
- **旋转**：左转 / 右转 90°，实时显示当前角度，可批量对多个选中页旋转
- **删除**：移除不需要的页面；不允许删光，至少保留一页
- **调整顺序**：上移 / 下移，支持多选连续移动
- **仅导出选中页**：把选中的页按当前顺序导出为新 PDF
- **导出全部页**：按当前顺序与旋转导出完整 PDF
- **重置**：一键回到原始文件状态，撤销所有改动
- **加密文件识别**：自动检测并提示先用「PDF 加密 → 移除密码」解除
- **输出保护**：`原文件名_页面管理.pdf` / `原文件名_选中页.pdf`，不覆盖原文件，重名自动追加序号

### PDF 提取图片
- **从 PDF 中导出所有内嵌图片**，每个 PDF 生成独立文件夹，按 `p页码_序号` 命名
- **双通道提取**：
  - `原始格式`（默认）— JPEG 图片取原始编码字节直接落盘，**字节完全一致、零重编码**；其余编码解码后存为 PNG（无损）
  - `统一 PNG` — 全部转为 PNG
  - `统一 JPEG` — 全部转为 JPEG（质量 92），体积更小
- **最小边长过滤**：默认 64 像素，自动忽略图标、项目符号等小图；填 0 不过滤
- **重复图片去重**：按 SHA-256 内容哈希判断，同一张 logo 在每页出现只导出一次
- **兼容性**：对 Flate/Predictor/ICC 等无法直取的编码，自动改用本地 PDF 引擎解码，保证不漏图
- **加密文件识别**：自动检测并提示先用「PDF 加密 → 移除密码」解除
- **批量处理**：单个失败不影响其余，结束后汇总提取张数

- **拖拽添加**：支持拖拽 PDF 文件到列表

### PDF 压缩
- **内置引擎，无需外部依赖**：本地 PDF 引擎负责读写容器，图片的 DPI 与 JPEG 质量由程序自行控制
- **自控画质**：先按「像素 ÷ 显示物理尺寸」算出每张图片的有效 DPI，超过目标值才重采样，再按指定质量重编码
- **四档预设**：
  - `轻度`（默认）— 不重采样，仅高质量重编码，画质接近原样
  - `标准` — 重采样到 200 DPI + 质量 88，体积与画质平衡
  - `强力` — 重采样到 150 DPI + 质量 82
  - `极限` — 重采样到 110 DPI + 质量 75，体积最小
  - `自定义` — 目标分辨率（不重采样 / 72~300 DPI）与 JPEG 质量（50~98）自由组合
- **文字与矢量不动**：只处理图片，文字层完整保留，压缩后仍可搜索、可复制
- **低分辨率图片不重编码**：有效 DPI 已低于目标的图片保持原样，避免无谓的画质损失
- **跳过已最优文件**：压缩后体积收益不足 1% 或不足 1 KB 时不生成副本，列表状态提示「已是最优」
- **加密文件识别**：自动检测并提示先用「PDF 加密 → 移除密码」解除
- **结果对比**：列表实时显示 `原始大小 → 压缩后 → 压缩率`
- **输出保护**：输出为 `原文件名_已压缩.pdf`，不覆盖原文件，重名自动追加序号
- **批量处理**：单个失败不影响其余，结束后汇总压缩数 / 跳过数 / 失败数

- **横竖版自适应**：按每页自身尺寸计算位置，横版页面同样贴边

- **加密文件识别**：自动检测并提示先用「PDF 加密 → 移除密码」解除
- **输出保护**：输出为 `原文件名_已加页码.pdf`，不覆盖原文件，重名自动追加序号
- **批量处理**：支持多个文件，单个失败不影响其余，结束后汇总

### Excel 拆分 / 合并
- **两种处理方式**：`按工作表拆分`（一个工作簿 → 每张表一个文件）、`合并为一个工作簿`（多个工作簿 → 一个文件）
- **保留完整格式**：拆分与合并都通过工作表复制实现，公式、格式、行列宽、合并单元格一并保留，不是重新生成
- **跳过隐藏工作表**：默认开启，拆分与合并都生效；关闭后隐藏表会一并处理，并在输出中自动设为可见
- **跳过空工作表**：默认开启，避免生成一堆空白文件
- **合并保留原名**：仅合并模式有效，勾选沿用原表名、重名自动追加 `_1`/`_2`；不勾选用「源文件名_表名」；合并结果弹窗会列出最终表名
- **自动清理默认空表**：新工作簿自带的空白 Sheet 会自动移除，输出干净
- **文件名安全处理**：工作表名中的非法字符自动替换，超长自动截断
- **输出保护**：拆分输出 `原簿名_表名.xlsx`；合并输出 `合并工作簿_日期时间.xlsx`，重名自动追加序号
- **批量处理**：拆分支持一次添加多个工作簿，单个失败不影响其余

### 图片批量处理
- **格式转换**：保持原格式 / 统一 JPG / 统一 PNG / 统一 BMP，支持 JPG、PNG、BMP、GIF、TIFF
- **批量缩放**：按宽度 / 按高度 / 按长边 / 按百分比，始终保持原始宽高比
- **高质量重采样**：缩小超过 2 倍时采用逐级减半的双三次缩放，细节明显优于一次性缩放
- **目标体积**：填「压到 N KB 以内」后自动二分搜索 JPEG 质量，在满足体积的前提下取最高画质，结果标注实际使用的质量值
- **零损失直通**：不改格式、不缩放、不限体积时**直接复制原文件**，不做任何重编码
- **拍摄方向纠正**：读取 EXIF 方向标记自动旋转，手机竖拍照片不会躺倒
- **透明处理**：转 JPG / BMP 时自动铺白底，转 PNG 时保留透明通道
- **多帧提示**：GIF / 多页 TIFF 只处理首帧，并在结果中明确标注
- **大图友好**：逐张处理并及时释放位图，8800×5000 的 16 MB 大图可正常处理
- **输出保护**：输出为 `原文件名_已处理.扩展名`，不覆盖原文件，重名自动追加序号

### 证件照排版
- **标准规格**：小一寸 22×32、一寸 25×35、大一寸 33×48、小二寸 35×45、二寸 35×49、大二寸 35×53（毫米）
- **相纸可选**：5 寸 127×89、6 寸 152×102、A4 210×297
- **自动排版**：按 300 DPI 计算可排行列数，整版在相纸上居中，间距可调（0~20 mm）
- **居中裁剪**：先按证件照长宽比居中裁剪再缩放，人像不变形；可关闭改为拉伸
- **留白裁切**：照片之间保留可调间距（默认 2 mm）作为裁切间隔，画面里不画任何辅助线，成片边缘干净
- **实时预览**：切换规格或相纸时立即显示「每张相纸可排 5 列 × 2 行 = 10 张」
- **方向纠正**：读取 EXIF 自动旋转手机竖拍照片
- **高质量缩放**：大幅缩小时逐级减半双三次缩放，人像边缘更干净
- **批量处理**：一次添加多张照片，每张各出一版排版图
- **输出保护**：输出为 `原文件名_证件照排版.jpg`，300 DPI，重名自动追加序号

### 提取纯文本
- **多格式支持**：PDF / Word（doc、docx、rtf）/ PPT（ppt、pptx）/ TXT / MD → `.txt`
- **PDF 阅读顺序重排**：按「页 → Y 坐标 → X 坐标」重排，多栏排版不会串行
- **中英文智能拼接**：中文之间不插入多余空格，西文之间保留空格
- **页眉页脚剔除**：自动去掉跨页重复的页眉页脚，以及行尾的「第 N 页 / 共 M 页」
- **格式清理**：连续空行压缩、页与页之间插入 `===== 第 N 页 =====` 分隔标记（可关闭）
- **两种输出**：每个文件生成一个 txt，或把全部内容**合并成一个 txt**（方便喂给 AI、做全文检索）
- **编码可选**：UTF-8 / UTF-8（带 BOM，Windows 记事本优先识别）/ GBK（兼容旧软件）
- **扫描件提示**：PDF 无文字层时明确提示「可能是扫描件，需要 OCR」，不会静默输出空文件
- **输出保护**：输出为 `原文件名.txt`，重名自动追加序号

### 文本翻译
- **两个免费引擎**：微软翻译（签名免密通道）、腾讯翻译君，**都不需要注册、不需要填 API Key**
- **双引擎自动降级**：首选引擎超时或被限流时，自动切换另一个引擎，并在状态栏说明原因
- **输入方式**：直接粘贴文本，或导入 TXT / MD（自动识别 UTF-8 / UTF-8 BOM / GBK 编码）
- **目标语言**：简体中文 / 繁体中文 / 英语 / 日语 / 韩语 / 法语 / 德语 / 西班牙语 / 俄语
- **源语言自动识别**：不用手动选，中文、英文、日文等都能自动判断
- **长文本分段**：按行与句子边界切分，每段不超过 1000 字符（微软单次上限），按原顺序拼回
- **重复段落去重**：同一段文字只请求一次，长文中的重复表头、说明不会重复翻译
- **排版保留**：空行与段落结构原样保留，不会把整篇挤成一段
- **结果处理**：一键复制译文、另存为 txt；每次翻译会自动在输出目录留一份备份
- **体积零增加**：纯 HTTP 调用，不引入任何第三方库

### OCR 文字识别
- **内置 PP-OCRv4 引擎**：PaddleOCR v4 检测 + 识别模型，中文印刷体实测 **97%** 准确率
- **零依赖运行**：推理走 OnnxRuntime（已内嵌），不需要 Office、不需要系统 OCR 语言包、不需要联网识别
- **模型按需下载**：首次使用自动下载约 15 MB 模型（PyPI 官方源 + 清华镜像双源），之后完全离线可用
- **模型缓存位置**：`C:\Users\<用户名>\AppData\Local\DocToPdfTool\models\ppocrv4\`（det.onnx 4.5 MB、rec.onnx 10.4 MB、cls.onnx 0.6 MB）；AppData 为隐藏目录，界面上的「模型目录」按钮可直接打开
- **识别对象**：图片（JPG/PNG/BMP/TIF）+ PDF（内置渲染器逐页识别，无需先转图片）
- **剪贴板快捷识别**：截图后直接点「粘贴识别」或按 Ctrl+V，立即识别剪贴板里最新的图片，不用先存文件
- **结果直接显示**：识别完成自动切到「识别结果」页，可一键复制全部文本，也可另存为 txt（同时保留自动落盘备份）
- **行合并优化**：检测出的碎片框按「垂直重叠 + 水平间距」自动合并成完整行，再按行聚类排序，不会把一句话拆成多段
- **页码可选**：PDF 支持 `1-3,5` 形式；渲染 DPI 200/300/400 可调
- **排版保留**：可保留 `===== 第 N 页 =====` 分隔，输出 UTF-8（带 BOM）txt
- **输出保护**：输出为 `原文件名.txt`，重名自动追加序号

> 实测：标准打印文档相似度 97.7%；图表密集页 60% 左右（受小字号与表格排版影响）。
> 手写体不支持。

zip 解压后是**同名文件夹**，内含 `DocToPdfTool.exe`、全部依赖 DLL 与 `README.md`，不会把文件散落在下载目录。

### Release 附件

两个脚本都会把最终产物统一放到 `publish\Release\`，并额外生成 `SHA256SUMS.txt` 供校验：

```
publish\Release\
├─ DocToPdfTool-v1.0.0.19-win-x64.exe   ← 单文件版
├─ DocToPdfTool-v1.0.0.19-win-x64.zip   ← 目录版（安装包）
└─ SHA256SUMS.txt                        ← 两个产物的 SHA-256
```

- 版本号自动读取 `DocToPdfTool.csproj` 的 `<Version>`，发版只需改这一处
- 中间产物位于 `publish\SingleFile\` 与 `publish\DirPublish\`
- 构建时会自动剔除 `.xml` 文档、`.pdb` 调试符号与 `app.config`

## 技术栈

- .NET Framework 4.8 / WPF
- COM 自动化（WPS / Office 后期绑定）
- Edge Chromium headless（HTML 转 PDF）
- **Spire.PDF 12.10.7**（PDF 转 Word / PPT 转 Word 中段，PDF 水印绘制、PDF 页面重排与旋转、PDF 提取图片的引擎解码兜底；本地 DLL 引用，无需 Office）
- **Spire.Doc 14.10.9**（Word 转 PDF / Word 转图片，本地 DLL 引用，无需 Office）
- **Spire.XLS 16.10.3**（Excel 转 PDF，以及 Excel 转图片的中间 PDF 生成；本地 DLL 引用，无需 Office）
- **Spire.Presentation 11.10.4**（PPT 转 PDF / PPT 转 Word / PPT 转图片，本地 DLL 引用，无需 Office）
- **矢量 EMF 重渲染**（Word 转图片：`Spire.Doc.SaveToImages(Metafile)` + GDI+ 按目标 DPI 绘制）
- **DocumentFormat.OpenXml**（DOCX 合并 / 内容清理）
- Word COM 自动化（PDF 转 Word，3 层回退创建真实 Word 实例）
- PdfPig 开源 PDF 解析（PDF 转 Excel 文本提取、拆分/合并的 PdfDocumentBuilder、PDF 提取图片的原始字节直取与 SHA-256 去重）
- 纯 XML xlsx 生成（`ZipArchive` + `XElement`，零 Office 依赖）
- Win32 API 窗口守卫（抑制 Office 弹窗）
- WMI 进程监控 + WinEventHook（Word 窗口自动隐藏）
- Windows.Data.Pdf 内置 PDF 渲染引擎（PDF 转图片/PPT/扫描件、Excel 转图片、PDF 页面管理缩略图，Windows 10+）
- 纯 XML pptx 生成（`ZipArchive` + `XElement`，图片嵌入幻灯片，零 Office 依赖）
- 纯 .NET PDF 写入（`BinaryWriter` + PDF 规范，零依赖嵌入 JPEG 图片；PDF 转扫描件 / 图片转 PDF 共用）
- ini 配置（`%APPDATA%\DocToPdfTool\config.ini`，默认保存目录持久化）
- Costura.Fody（单文件打包）
